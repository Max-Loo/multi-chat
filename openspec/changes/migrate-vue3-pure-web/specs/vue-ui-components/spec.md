# Spec Delta

## Purpose

定义 Vue 3 组件体系的行为契约：基础 UI 组件、Markdown/代码渲染、Toast、虚拟滚动、表格/表单、图标、分栏与瀑布流等均以 Vue 等价实现，视觉与交互和迁移前对等。

## ADDED Requirements

### Requirement: 基础组件对等

系统 SHALL 以 Vue 等价组件提供既有全部基础 UI 能力（对话框、警告对话框、下拉菜单、选择器、弹出层、工具提示、开关、复选框、单选组、进度、标签、头像、密码输入、分页等），交互与键盘可达性行为对等。

#### Scenario: 对话框交互

- **WHEN** 用户打开对话框后按 Escape 或点击遮罩
- **THEN** 对话框关闭，焦点管理行为与迁移前一致
- **AND** 警告对话框的描述关联（a11y 既有规格）保持

#### Scenario: 下拉与选择器键盘导航

- **WHEN** 用户使用键盘操作下拉菜单或选择器
- **THEN** 焦点移动、选中与关闭行为与迁移前一致

### Requirement: 消息渲染体系

系统 SHALL 保持 Markdown 渲染、代码高亮、代码块复制、流式增量渲染与 HTML 净化的既有行为（渲染管线为框架无关层，行为不变）。

#### Scenario: 消息气泡渲染

- **WHEN** 聊天消息包含 Markdown、代码块或 HTML 内容
- **THEN** 渲染结果、高亮语言索引、复制按钮行为与迁移前一致
- **AND** 不安全 HTML 被净化，不执行任意脚本

#### Scenario: 流式渲染

- **WHEN** 助手消息以流式方式逐步到达
- **THEN** 分块拆分与增量渲染的既有性能行为保持（含推理内容传播的既有规格）

### Requirement: Toast 通知

系统 SHALL 以 Vue 等价 Toast 实现保持既有通知行为，与既有 Toast 队列服务衔接。

#### Scenario: Toast 展示与队列

- **WHEN** 应用触发成功/错误/警告通知
- **THEN** Toast 按既有队列顺序展示、自动消失与手动关闭行为一致
- **AND** 移动端 Toast 定制行为保持

### Requirement: 虚拟滚动长列表

系统 SHALL 保持聊天长列表的虚拟滚动行为（仅渲染可视区消息），滚动状态管理与迁移前一致。

#### Scenario: 大量消息滚动

- **GIVEN** 单个聊天包含数百条消息
- **WHEN** 用户快速滚动列表
- **THEN** 滚动流畅，可视区外消息不参与渲染
- **AND** 滚动位置恢复、底部跟随等既有行为保持

### Requirement: 表格与表单

系统 SHALL 保持模型管理表格（排序、分页、行操作）与设置/创建表单（校验、提交、错误提示）的行为对等。

#### Scenario: 模型表格操作

- **WHEN** 用户对模型表格进行排序或翻页
- **THEN** 行为与迁移前一致（含既有分页规格）

#### Scenario: 表单校验

- **WHEN** 用户提交未通过校验的表单（如模型配置）
- **THEN** 校验错误就地展示且不提交，行为与迁移前一致

### Requirement: 图标与视觉一致性

系统 SHALL 以 Vue 等价图标库替换既有图标，Tailwind 主题变量、动画与破坏性按钮主题等视觉规格保持不变。

#### Scenario: 图标渲染

- **WHEN** 渲染既有界面
- **THEN** 图标语义、尺寸与配色和迁移前一致
- **AND** 亮/暗主题下的视觉表现不变

### Requirement: 分栏与瀑布流布局

系统 SHALL 保持可调分栏面板与瀑布流（Provider 网格）布局行为。

#### Scenario: 分栏拖拽

- **WHEN** 用户拖动分栏分隔条
- **THEN** 区域比例实时调整，比例行为与迁移前一致

#### Scenario: 瀑布流网格

- **WHEN** 渲染模型供应商网格
- **THEN** 瀑布流列数随视口宽度自适应，与迁移前一致

### Requirement: 可访问性

系统 SHALL 保持既有可访问性规格（a11y 工具、焦点顺序、语义化查询、ARIA 属性）在 Vue 组件中的对等实现。

#### Scenario: 键盘可达性

- **WHEN** 用户仅使用键盘遍历主要界面
- **THEN** 焦点顺序与可达性与迁移前一致
