# Spec Delta

## Purpose

定义 i18next 核心之上的 Vue 响应式绑定行为契约：语言切换的响应式传播、语言包懒加载与既有 i18n 服务层（初始化、缓存验证、Toast 提示、自动持久化、完整性检查）的无缝衔接。

## ADDED Requirements

### Requirement: 响应式翻译

系统 SHALL 提供组件层的响应式翻译绑定：语言变更后，所有已渲染界面的文本即时更新，无需刷新页面。

#### Scenario: 语言切换即时生效

- **GIVEN** 界面已渲染出导航、按钮、设置页等多种文案
- **WHEN** 用户将语言从中文切换为英文
- **THEN** 全部已渲染文案即时更新为英文
- **AND** 之后新渲染的组件直接使用新语言

#### Scenario: 响应式失效防护

- **WHEN** 语言切换发生在异步组件或延迟渲染的组件上
- **THEN** 这些组件渲染时使用当前语言，不出现新旧语言混杂

### Requirement: 语言包懒加载

系统 SHALL 保持语言包按需加载与缓存行为：仅加载所需语言包，加载失败时按既有降级策略处理。

#### Scenario: 首次切换到未加载语言

- **WHEN** 用户首次切换到尚未加载的语言
- **THEN** 系统异步加载该语言包
- **AND** 加载期间界面保持可用，加载完成后文案更新

#### Scenario: 语言包加载失败

- **WHEN** 语言包网络加载失败
- **THEN** 系统按既有降级策略回退到可用语言并提示，不白屏

### Requirement: 翻译回退与完整性

系统 SHALL 保持翻译缺失时的回退行为与既有翻译完整性检查（安全翻译、分支排除、lint 检查）的约束。

#### Scenario: 缺失键回退

- **WHEN** 某翻译键在当前语言中缺失
- **THEN** 系统回退到默认语言显示，不渲染原始键名或空文本
- **AND** 现有翻译完整性检查脚本对迁移后的代码仍然有效

### Requirement: 服务层行为保持

系统 SHALL 保持既有 i18n 服务层行为不变：初始化步骤、语言变更的自动持久化、变更时的 Toast 提示队列与缓存验证机制。

#### Scenario: 语言偏好持久化

- **WHEN** 用户切换语言后关闭并重新打开应用
- **THEN** 应用以上次选择的语言启动

#### Scenario: 语言变更提示

- **WHEN** 语言变更触发既有 Toast 提示逻辑
- **THEN** 提示以目标语言呈现，队列行为与迁移前一致
