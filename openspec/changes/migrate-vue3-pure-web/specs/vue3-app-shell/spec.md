# Spec Delta

## Purpose

定义 Vue 3 应用外壳的行为契约：应用入口挂载、路由结构与懒加载、主题系统、响应式布局与全局错误处理，均与迁移前的用户可感知行为保持对等。

## ADDED Requirements

### Requirement: 应用入口挂载

系统 SHALL 以 Vue 3 应用实例挂载根组件，且应用初始化流程在 UI 挂载前按既有步骤完成。

#### Scenario: 正常启动

- **WHEN** 用户打开应用
- **THEN** 初始化步骤（keyring 迁移、i18n、主密钥、模型、聊天列表、应用配置、模型供应商）按既有顺序与依赖关系执行
- **AND** 初始化完成后渲染应用界面（含启动加载/Logo 动画，与迁移前一致）

#### Scenario: 初始化失败

- **WHEN** 任一关键初始化步骤失败
- **THEN** 系统按既有三级错误处理策略呈现错误界面，错误信息可读且支持重试路径

### Requirement: 路由结构与懒加载

系统 SHALL 保持既有路由结构与按需加载行为，页面组件按路由按需加载。

#### Scenario: 路由结构对等

- **WHEN** 用户访问 `/`、`/chat`、`/model`、`/setting` 及未匹配路径
- **THEN** 分别渲染聊天页、模型页、设置页与 404 页，重定向规则与迁移前一致
- **AND** 路由切换时 URL 同步行为保持（含聊天删除后的 URL 同步等既有规格）

#### Scenario: 页面按需加载

- **WHEN** 首屏加载应用
- **THEN** 仅加载入口与当前路由所需的代码分包
- **AND** 首次导航到某页面时才加载该页面对应的分包

#### Scenario: 深层路由直达

- **GIVEN** 应用部署在配置的基础路径下
- **WHEN** 用户直接访问或刷新深层路由 URL
- **THEN** 应用正常加载并渲染对应页面（与迁移前的部署行为一致）

### Requirement: 主题系统

系统 SHALL 提供亮色/暗色/跟随系统三种主题模式，持久化用户选择并即时生效，行为与迁移前一致。

#### Scenario: 主题切换与持久化

- **WHEN** 用户切换主题模式
- **THEN** 全局配色立即更新
- **AND** 用户选择被持久化，下次启动保持

#### Scenario: 跟随系统

- **GIVEN** 主题模式为"跟随系统"
- **WHEN** 操作系统在亮色/暗色间切换
- **THEN** 应用主题自动跟随变化

### Requirement: 响应式布局

系统 SHALL 保持桌面端与移动端两套布局的响应式切换行为（侧边栏、底部导航、抽屉），与迁移前一致。

#### Scenario: 视口切换布局

- **WHEN** 视口宽度跨越既有断点（桌面 ↔ 移动）
- **THEN** 布局在侧边栏模式与底部导航/抽屉模式间切换
- **AND** 抽屉开合状态、遮罩行为与迁移前一致

### Requirement: 全局错误处理

系统 SHALL 保持既有全局错误处理行为：错误边界拦截渲染异常、Toast 呈现非致命错误、致命错误呈现专用界面。

#### Scenario: 渲染异常拦截

- **WHEN** 某页面组件在渲染中抛出未捕获异常
- **THEN** 系统不出现白屏，按既有错误处理策略呈现提示或错误界面
