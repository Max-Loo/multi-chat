# 文档维护约定

本文件规定 AGENTS.md 与 `docs/` 子文档的分工、内容取舍标准和同步规则。AGENTS.md 只保留面向 coding agent 的核心指导，完整的维护流程在本文档维护。

## 内容分类规则

| 类别                         | 处理方式                 | 示例                            |
| ---------------------------- | ------------------------ | ------------------------------- |
| **必要信息**                 | 保留在 AGENTS.md         | 项目架构、开发规范、关键约定    |
| **可查询且易定位的信息**     | 删除，提供文件引用       | Tauri 插件列表 → `package.json` |
| **可查询但定位成本高的信息** | 保留为快速查找表         | 核心文件路径表                  |
| **详细示例**                 | 删除，保留简要说明       | API 使用示例 → 指向源文件       |
| **重复内容**                 | 合并为一段               | HTTP 插件说明（3 段 → 1 段）    |
| **过时数据**                 | 删除                     | 测试覆盖率统计、当前行数统计    |
| **详细设计说明**             | 移到 `docs/design/`      | 架构设计、流程说明              |
| **项目约定**                 | 移到 `docs/conventions/` | 最佳实践、使用规范              |

"定位成本"的判断标准：直接出现在 `package.json`、入口文件等显眼位置的信息，定位成本低；需要多次 glob/grep 才能找到的信息，定位成本高。

## 文档拆分决策树

```
是否为 AGENTS.md 的核心信息？
├─ 是 → 保留在 AGENTS.md
└─ 否 → 继续判断
    ├─ 设计决策或架构说明？ → docs/design/
    ├─ 项目约定或最佳实践？ → docs/conventions/
    ├─ 可从代码中直接查询且定位成本低？ → 删除，提供文件路径引用
    └─ 否 → 在代码中添加注释
```

## 添加新内容检查清单

在 AGENTS.md 中添加新内容前，先确认：无法从代码查询（或定位成本高）、符合文档结构、无冗余示例、无重复内容、提供文件引用、不属于子文档范畴。

## 优先级原则

对于实现细节：

- **优先**：在代码中添加详细注释
- **其次**：在 README.md 中添加使用说明
- **然后**：在 docs/design/ 或 docs/conventions/ 中添加详细文档
- **最后**：在 AGENTS.md 中添加架构说明（仅核心信息）

## docs/ 目录结构规范

`docs/design/` - 设计文档（架构、流程、决策）
`docs/conventions/` - 项目约定（最佳实践、规范）
`docs/reference/` - 参考文档（外部教程、指南）
`docs/README.md` - 完整文档索引

命名规范：小写 + 连字符（如 `lazy-loading.md`）

新增文档后必须在 `docs/README.md` 登记索引（目录树、对应章节、按主题查找表三处）。

## 维护规范

- **保持精简**：AGENTS.md 目标 **250 行以内**；超过时必须拆分到子文档
- **行数不写进文档**：当前行数用 `wc -l AGENTS.md` 查询，不在 AGENTS.md 中记录统计数字
- **及时更新**：架构变更时同步更新 AGENTS.md 和相关子文档
- **定期审查**（维护者任务）：每季度检查一次文档行数和内容质量
- **版本控制**：通过 git 提交记录变更，不创建 `.bak` 等备份文件

## 文档同步要求

每次修改文件时，检查相关改动是否需要同步到文档：

- **修改了代码**：
  - 如果改动影响架构 → 更新 AGENTS.md 或 docs/design/
  - 如果改动影响约定 → 更新 docs/conventions/
  - 如果改动可从代码查询且定位成本低 → 无需更新文档

- **修改了 AGENTS.md**：
  - 详细说明不放在 AGENTS.md：放到 `docs/design/`，AGENTS.md 只留一行指针
  - 约定内容不放在 AGENTS.md：放到 `docs/conventions/`，AGENTS.md 只留一行指针

- **修改了子文档**：
  - 检查是否需要在 AGENTS.md 中更新索引或概述
  - 检查是否需要在 docs/README.md 中更新索引

- **README.md 简洁原则**：只增加绝对必要的内容

- **README 双语同步硬约束**：修改 `README.md`（英文版）或 `README.zh-CN.md`（中文版）任一文件时，**必须**同步翻译另一版本，且两个版本的章节结构必须保持一致
